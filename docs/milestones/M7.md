Fixes made to get there:

- **A leftover `public/robots.txt` from M0** ("Disallow: /") overrode the `robots.txt` endpoint, so even the real domain would never have been crawlable. It is removed.
- **Fonts use `font-display: optional`** (with the preload). When the subset font arrives late on a first visit, the page keeps the system font instead of jumping, which caused about 0.1 layout shift and the relayout counted in blocking time. It is cached for every page after.
- **The tooth diagram reserves its space** (`width`, `height` and `aspect-ratio`).
- **`text-rendering: optimizeLegibility` is dropped** (costly text shaping, no visible gain).

The local machine was busy during these runs, so scores vary by a few points between runs. CI's runner is the gate.
